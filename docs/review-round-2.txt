Why the assessment improved from 7.8:
- Position keeps the continuous concatenated path, including the reached far-right tape when a partial workspace transition settles back. Normal/cancelled releases on both sides of the midpoint are covered.
- The acceleration gain is now integrated across the actual speed-filter trajectory. Independent numerical-quadrature tests support packet-independent accelerated displacement, including saturation crossings.
- Release velocity now ages smoothly instead of falling off a 100 ms cliff. Maximum velocity is bounded before ageing, preventing an old huge input sample from launching a full fling after a pause.
- The runtime integrates a normal 120 ms frame stall in full. The separate suspend guard suppresses stale travel after much longer gaps.
- Raw swipe-begin holds kinetic motion before horizontal classification, and raw end releases a hold even when no horizontal gesture was claimed.
- Abort, cancel, config reload and library unload reconcile keyboard focus with the visible workspace. Explicit user focus is distinguished from automatic/background focus changes.
- Background page topology is refreshed and the continuous coordinate is rebased without displacing the held view or the private settling target. Visible topology changes abort safely and defer focus until layout mutation completes.
- Old controller inhibition is restored when hidden pages become fullscreen, replace data, or leave the monitor. Removed pages also release their owned visual state.
- Covering fullscreen windows are one visible page, avoiding invisible hidden-column travel. Strong workspace retention supports ordinary empty source workspaces during a swipe.
- Direct-scanout inhibition is scoped to a synchronous render check, removing the long-lived global-state snapshot that could clobber another plugin.
- Both replay entrypoints reject numeric instance aliases and validate disposable fixtures before mutating compositor state.
